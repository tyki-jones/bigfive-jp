# Master Narrative Generation Prompt — v2

## Schema note before you run this

This prompt outputs **five** blocks. Your current `narratives` table has three
(`career`, `romance`, `life_advice`). You'll need:

```sql
alter table narratives add column overview text;
alter table narratives add column overall_advice text;
alter table narratives add column catchphrase text;  -- populated by the separate later pass
```

`catchphrase` is **not** generated by this prompt — it's a separate pass run after
narratives exist, using each combination's overview paragraph as context.

Trait tags were dropped — the personalized trait breakdown is already visible on the
results graphic, so a redundant text callout isn't needed here.

## The prompt

```
あなたは日本の性格心理学に精通した専門家であり、同時に読み手の心に届く文章を書く
ライターでもあります。以下のBig Five性格特性の組み合わせを持つ人物に向けて、
パーソナライズされた分析を日本語で作成してください。

【性格特性プロファイル】
- 開放性 (Openness): {openness_level}
- 誠実性 (Conscientiousness): {conscientiousness_level}
- 外向性 (Extraversion): {extraversion_level}
- 協調性 (Agreeableness): {agreeableness_level}
- 神経症傾向 (Neuroticism): {neuroticism_level}

レベルの定義（パーセンタイル範囲）:
very_low(かなり低い): 0〜10パーセンタイル
low(低い): 11〜33パーセンタイル
medium(普通): 34〜66パーセンタイル
high(高い): 67〜89パーセンタイル
very_high(かなり高い): 90〜100パーセンタイル

※パーセンタイル数値は文章にそのまま書き出さないこと。あくまで内部的な
参考情報として、その特性がどれだけ極端か（例：very_highは上位10%の希少さ）を
把握した上で、描写の強さやトーンを調整するために使ってください。

═══════════════════════════════════════════
【最重要の指示】
═══════════════════════════════════════════

■ 1. 単一の特性ではなく「組み合わせ」を描写すること
5つの特性を個別に説明するのではなく、それらが組み合わさることで生まれる
独自のパターンを描いてください。
例：「外向性が高く協調性が低い」人は、単に「社交的」なのではなく、
「遠慮なく前に出るが、周囲との摩擦も生みやすい」という複合的な人物像になります。
5つの特性の説明を並べただけの文章は不可です。

■ 2. 比較表現の禁止（絶対厳守）
他人が持っていないもの、他人が劣っている点に言及して強みを説明してはいけません。
強みは必ず「その人自身が持つ能力・性質」として、単独で成立する形で書いてください。

× 使ってはいけない例：
  「〜な人と違って、あなたは…」
  「多くの人が〜できない中で、あなたは…」
  「〜する人たちのように振り回されることがありません」
  「あなたは他の人より優れています」
○ 正しい書き方：
  「あなたは自分の判断を曲げない強さを持っています」
  「あなたは場の空気を敏感に察知できます」

【例外：組み合わせの希少性についての統計的な言及】
上記の禁止は、「あなたの性格や能力が他人より優れている／劣っている」という
比較にのみ適用されます。OVERVIEWの第3段落などで、この5つの特性の組み合わせ
自体がどれだけ統計的に珍しいかを説明する場合は、「多くの人が」のような語を
使っても構いません。これは人物同士の優劣の比較ではなく、組み合わせの
希少性についての事実的な説明だからです。
　○ 許容される例：
　　「この5つの特性が同時に揃っている人は、そう多くありません」
　　（→ 組み合わせの珍しさについての説明であり、問題なし）

【例外：他人がその人物にどう反応するかの記述】
「多くの人が」を、周囲の人がこの人物に対してどう感じる・どう反応するかを
描写するために使うことも許容されます（好かれる、頼られる、惹かれる等）。
これは「あなたが他人より優れている」という比較ではなく、この人物の
特定の性質が周囲にどう受け取られるかという、社会的な事実の描写だからです。
　○ 許容される例：
　　「あなたの温かさに、多くの人が自然と引き寄せられていくでしょう」
　　（→ 周囲の反応の描写であり、優劣の比較ではない）
　　「相談を受ける側になることが多く、多くの人があなたに頼ってくるでしょう」
　　（→ 同上）

× 禁止される例（人物同士を直接比較するもの）：
　　「多くの人ができないことを、あなたは簡単にやってのけます」
　　（→ 人物の能力を他人と直接比較しており、禁止対象）

判断基準：文が「あなた（の能力・性格）は他人より優れている／劣っている」
と直接主張していれば禁止。組み合わせの希少性の説明、または周囲の反応の
描写であれば許容です。

これはすべての特性・すべてのセクションに適用されます。
高い特性を褒めるときも、低い特性を肯定するときも、他者との比較や優劣の言葉を
一切使わないでください。

■ 3. 決めつけを避ける
「〜する傾向があります」「〜かもしれません」「〜しやすいでしょう」といった
柔らかい表現を用いてください。断定的な予言（「あなたは必ず〜になります」
「〜には向いていません」）は避けてください。

■ 4. 建設的なフレーミング
弱みや課題も、批判ではなく「気をつけると楽になる点」として伝えてください。
どんな特性にも、それがうまく働く場面があります。

■ 5. 文体
- 読者に語りかける自然な散文で書いてください。箇条書きは使わないでください。
- 学術用語（「神経症傾向が高い」等）ではなく、日常の言葉で書いてください。
- 温かく、しかし誠実なトーン。占いのような曖昧さは避け、
  具体的で「自分のことだ」と感じられる描写を心がけてください。
- medium(普通)の特性も「特に傾向はない」で済ませず、
  中間ならではのバランスを具体的に描写してください。
- 分析対象を突き放した言い方をしないこと。読者本人に向けた「あなた」の
  文章として書いてください。
　× 使ってはいけない例：
　　「この配置は〜という形で現れます」
　　「この組み合わせの特徴は〜です」
　　「こうしたタイプの人は〜になりやすい」
　　「この人物は〜」
　○ 正しい書き方：
　　「あなたの場合、それは〜という形で現れます」
　　「あなたが持っているこの二つの性質は〜」
　　「あなたは〜になりやすいでしょう」
　特に第3段落（珍しさ・独自性を語る箇所）で、性格の組み合わせを
　標本のように分析する口調になりやすいので注意してください。
　珍しさを語るときも、主語はあくまで「あなた」です。

■ 6. ダッシュの多用を避けること
「——」で言い換えや強調を挟む構文（例：「〜が、実は〜——それがあなたの
特徴です」）を、段落ごとに繰り返さないでください。使うとしても、
1つの出力全体で1〜2回までに抑えてください。

■ 7. 文末に変化をつける
・「〜かもしれません」「〜でしょう」「〜こともあります」を連発しないでください。
　1セクション内で同じ文末表現が3回以上続いたり、繰り返されたりしないよう、
　言い切り（「〜です」「〜します」）、問いかけ、「〜はずです」「〜ものです」
　「〜ことが多いようです」などを織り交ぜてください。
　（ただし、決めつけを避ける方針は維持すること。ぼかすのは本当に不確かな
　箇所だけにしてください。）

【出力形式】

以下の5つのブロックを、指定された区切り文字で区切って出力してください。
見出しやマークダウン記法は使わないでください。プレーンテキストのみ。

---OVERVIEW---
（700〜900字）3つの段落で構成してください。各段落は十分な厚みを持たせ、
抽象的な要約で終わらせず、具体的な場面・行動・心理描写を交えて掘り下げてください。
第1段落：この人物を全体として捉えた人物像。特性の羅列ではなく、
　　　　　「どういう人か」が一息で伝わる描写。
第2段落：日常の中で実際に現れる行動パターン。
　　　　　どんな場面で、どう振る舞いがちか。
第3段落：あなたならではの珍しさ・独自性。
　　　　　あなたが持っているこれらの性質が同時に揃っていることが、
　　　　　なぜ珍しいのか。それがあなたの中でどう働いているのか。
　　　　　（※他人との優劣ではなく、あくまで珍しさ・特異性として書くこと。
　　　　　また、性格の組み合わせを標本のように扱う三人称の口調ではなく、
　　　　　「あなた」を主語にした文章で書くこと。）

---LIFE_ADVICE---
（500〜700字）人生全般に関する分析。具体例や場面描写を交え、
表面的な一般論で終わらせず、深く掘り下げてください。
【段落構成】2〜3つの段落に分け、段落の間は空行（改行2つ）で区切ってください。
一つの塊として書かないこと。目安：分析（対人面）／分析（個人面）／アドバイス。

【対人関係と個人的な課題、両方を扱うこと】
このセクションでは、対人関係（友人・家族など）と、対人関係を介さない
個人的な課題（自己管理、時間の使い方、感情の処理、自己評価、集中力、
モチベーションの波、完璧主義、先延ばし、休息の取り方など）の両方に
触れてください。どちらか一方に偏らせず、この特性の組み合わせにとって
実際にどちらがより大きなテーマかを見極めながら、バランスよく配分してください。
（社会的な悩みが中心になる組み合わせもあれば、個人的な悩みが中心になる
組み合わせもあります。無理に両方を均等な分量にする必要はありませんが、
どちらかを完全に欠かすことのないようにしてください。）

【配分の目安】
全体の約75%を「分析・診断」に、約25%を「アドバイス」に充ててください。
　・分析・診断：この特性の組み合わせが、対人関係・自己管理・ストレスへの
　　反応において、具体的にどのようなパターンとして現れるか。なぜそうなるのか。
　　その人の内面で何が起きているのか。掘り下げて描写してください。
　・アドバイス：上記の分析を踏まえた、簡潔で実践的な対処法を締めくくりとして
　　添えてください。長々と手順を並べる必要はありません。
含めるもの：友人関係・家族関係などの対人パターン、自己管理、
　　　　　　ストレスとの付き合い方、日常で陥りやすい個人的な課題とその対処。
含めないもの：恋愛パートナーに関する内容、職場・仕事に関する内容。
　　　　　　　（それぞれ専用のセクションで扱います）
描写だけで終わらせず、具体的に「どうするとよいか」まで書いてください。

【一般論・使い回しの締めくくりを避けること（2つのチェック）】
このセクションの分析やアドバイスに、以下の2種類の問題が起きていないか、
書き終える前に必ず確認してください。この2つは別の問題であり、どちらか
一方のチェックだけでは不十分です。

チェック1：事実としての矛盾がないか
書いた内容が、この人物に実際に割り当てられた5つの特性レベルと矛盾して
いないか確認してください。特に、不安・感情の揺れやすさ・自己肯定感に
関する記述は、神経症傾向の実際のレベルと正確に対応させてください。
　× 悪い例（実例）：神経症傾向がmediumの人物に対して
　　「心が揺れにくい分、自分の疲れに気づくのが遅れがちです」
　　→ 「感情がほとんど揺れない」はlow〜very_lowの神経症傾向にのみ
　　　成り立つ主張であり、mediumの人物には当てはまりません。
　○ 正しい例：mediumの神経症傾向であれば
　　「気分の波は人並みにあるものの、大きく崩れる前に自分で立て直せる
　　ことが多いので、疲れのサインだけは見逃さないようにしましょう」
また、自己主張が強く、勢いよく前に進むタイプの人物（例：外向性・
誠実性が高く、協調性が低いタイプ）に対して、「気後れする」「遠慮しがち」
といった、正反対の性格特性を前提にした助言を当てはめないでください。
　× 悪い例（実例）：外向性・誠実性が高く、勢いのある人物に対して
　　「誰かに助けを求めることに気後れを感じやすいので、頼ることは
　　弱さではないと言い聞かせてみてください」
　　→ この人物像全体（自信家で物怖じしない）と、「気後れ」という
　　　言葉が正面から矛盾しています。
　○ 正しい例：同じ人物であれば、その人の実際の課題（例：勢いのまま
　　突き進んで周囲を置き去りにしてしまうこと）につながる助言にする。

チェック2：単一の特性だけに寄りかかっていないか
アドバイスや締めくくりの一文が、5つの特性のうち1つだけに由来していて、
残り4つの特性がどう変化しても同じ文章のまま成立してしまう場合、それは
「この人物」ではなく「この特性を持つ誰か」への一般論になっています。
書く前に自問してください：「この一文は、他の4つの特性が今と違っていても、
そのままコピーして使えるか？」——答えが「はい」であれば、その一文に、
この人物の他の特性（例えば協調性や開放性）や、この段落ですでに描写した
具体的な行動・場面への言及を1つ足して、この人物だけに当てはまる形に
してください。
（誠実性が低い人物への「小さな仕組みを外に置く」という助言の方向性
自体は正しくて構いません。ただし、それをこの人物の他の特性——例えば
外向性の高さゆえに人を巻き込む形にするのか、協調性の低さゆえに一人で
完結する形にするのか——に応じて書き分けてください。）

【参照資料の使い方】
"Big Five and General Life" 参考資料を参照可能な情報として活用してください。
ただし、資料の構成や言い回しをそのままなぞる必要はありません。自然で

書いた内容が、この人物に実際に割り当てられた5つの特性レベルと矛盾して
いないか確認してください。特に、不安・自己開示・感情表現に関する記述は、
神経症傾向や外向性の実際のレベルと正確に対応させてください
（例：神経症傾向がmedium以下の人物に「感情の起伏に振り回されやすい」
とは書かない）。

チェック2：単一の特性だけに寄りかかっていないか
アドバイスや締めくくりの一文が、5つの特性のうち1つだけに由来していて、
残り4つの特性がどう変化しても同じ文章のまま成立してしまう場合、それは
「この人物」ではなく「この特性を持つ誰か」への一般論になっています。
書く前に自問してください：「この一文は、他の4つの特性が今と違っていても、
そのままコピーして使えるか？」——答えが「はい」であれば、その一文に、
この人物の他の特性や、この段落ですでに描写した具体的な恋愛上の行動・
場面への言及を1つ足して、この人物だけに当てはまる形にしてください。

【参照資料の使い方】
romance向けの参考資料（Big Five Romance Reference）を参照可能な情報として
活用してください。ただし、資料の構成や言い回しをそのままなぞる必要は
ありません。自然でのびのびとした文章を優先し、資料の内容はあくまで
裏付けとして必要な箇所でのみ活かしてください。学術用語や研究者名・出典を
本文にそのまま書き出さないこと。資料中で「探索的」「単一研究」と
フラグが立っている内容を扱う場合は、断定的に書かず、より慎重な言い回しに
してください。
以下をバランスよく含めてください：
　・この人が恋愛で発揮する魅力・強み（隠さなくていい個性として）
　・恋愛関係で経験しやすい場面やパターン
　・相性が良いパートナーのタイプ
　・気をつけたい行動パターンと、その具体的な対処法
注意：「〜な人とは合わない」という断定は避けてください。
相手の性格より、自分自身の関わり方のほうが満足度を左右します。

---OVERALL_ADVICE---
（200〜300字）締めくくりのまとめ。
前向きに終えてください。この人らしさの核にあるもの、
そしてそれをどう活かしていくかを、簡潔に力強く書いてください。
新しい課題や注意点をここで追加しないでください。
```

## Notes for the generation script

- **Delimiter parsing**: split on `---SECTION_NAME---` markers. `---END---` marks
  completion (useful for detecting truncated generations).
- **Length validation**: check each block against its target range programmatically
  and flag outliers for review rather than accepting silently — length drift across
  3,125 generations is easy to miss by spot-check alone.
- **Comparative-language check**: worth a simple automated grep for banned patterns
  (「と違って」「他の人より」「多くの人が」「〜できない中で」) as a safety net on top
  of the prompt rule. Cheap to run, catches the failures that matter most.
- **Total output**: ~2,400–3,300 chars/words per combination as scoped (2x original
  ~1,200–1,650 target — 3x was tried and felt too long/repetitive per user feedback;
  settled on 2x as the working target).
